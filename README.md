# Barbershop Bot

Telegram-бот записи в барбершоп на [aiogram](https://docs.aiogram.dev/) 3.

Клиент выбирает свободную дату и время через инлайн-кнопки (занятые даты и
слоты помечены и недоступны для выбора), оставляет имя и телефон — заявка
уходит владельцу, а слот помечается занятым.

## Настройка

Переменные окружения:

- `BOT_TOKEN` — токен бота от [@BotFather](https://t.me/BotFather)
- `OWNER_CHAT_ID` — числовой Telegram ID владельца (узнать можно через
  [@userinfobot](https://t.me/userinfobot))

Расписание (часы работы, длительность слота, выходной день, горизонт
записи) настраивается в блоке "НАСТРОЙКИ" в начале `bot.py`.

## Команды владельца

- `/schedule` — показать расписание (свободные/занятые слоты)
- `/cancel ГГГГ-ММ-ДД ЧЧ:ММ` — отменить запись и освободить слот

## Локальный запуск

```bash
pip install -r requirements.txt
BOT_TOKEN=... OWNER_CHAT_ID=... python bot.py
```

## Деплой

Репозиторий готов для Railway / Render / Heroku — они подхватят
`Procfile` (`worker: python bot.py`), `requirements.txt` и
`.python-version` автоматически. Достаточно подключить репозиторий и
задать переменные окружения `BOT_TOKEN` и `OWNER_CHAT_ID`.
